# PP_Proktoring2026

Проект для прокторинга (автоматизированной проверки экзаменов).

## Краткое описание

Приложение содержит бэкенд в папке `app/`, небольшой фронтенд-переклад в `frontend/` и вспомогательные инструменты в `SolutionDevelopment/`.

- `app/` — основной Python-приложение и сервисы
  - `app/main.py` — точка входа приложения
  - `app/core/` — конфигурация, подключение к базе данных, модели
  - `app/endpoints/` — API-эндпоинты
  - `app/PYDmodels/` — Pydantic-схемы
  - `app/services/` — бизнес-логика (например, `proctor_service.py`)
- `frontend/` — статичные тестовые страницы (например, `test.html`)
- `SolutionDevelopment/` — экспериментальные/вспомогательные скрипты (например, `EyeChecker.py`, `ToolForMarking.py`)

## Быстрый старт (Windows, cmd.exe)

1) Клонируйте репозиторий (если ещё не склонирован):

```cmd
git clone <repo-url>
cd PP_Proktoring2026
```

2) Создайте и активируйте виртуальное окружение:

```cmd
python -m venv venv
venv\Scripts\activate
```

3) Установите зависимости:

```cmd
pip install -r requirements.txt
```

4) Запуск приложения:

```cmd
python app\main.py
```

После запуска обратите внимание на вывод в консоли — приложение может поднять сервер, подключиться к БД или выполнить иные задачи в зависимости от реализации `app/main.py`.

## Конфигурация

Файлы конфигурации находятся в `app/core/config.py`. Перед запуском проверьте там параметры подключения к базе и прочие настройки (например, порты, пути к моделям и т.д.).

## Структура БД

Модели и логика работы с БД расположены в `app/core/database.py` и `app/core/models.py`. Откройте эти файлы, чтобы увидеть используемую СУБД и схему данных.

## API

Эндпоинты расположены в `app/endpoints/endpoints.py` — там можно посмотреть доступные маршруты и формат запросов/ответов (Pydantic-схемы находятся в `app/PYDmodels/schemas.py`).

## Разработка

- Добавляйте новые зависимости в `requirements.txt`.
- Покрывайте критическую логику тестами и добавляйте их в репозиторий.
- Для локальной разработки используйте виртуальное окружение и перезапускайте приложение при изменениях.
